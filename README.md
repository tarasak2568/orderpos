## 🎯 วิธีการใช้งาน

### 1️⃣ พนักงานรับออเดอร์ (POS)

1. เปิด `/pos.php`
2. เลือก **โต๊ะ** ที่ลูกค้านั่ง
3. เลือก **หมวดหมู่** (อาหารแนะนำ, จานเดียว, เครื่องดื่ม ฯลฯ)
4. คลิก **เมนูอาหาร** ที่ลูกค้าสั่ง (กดซ้ำเพื่อเพิ่มจำนวน)
5. กดปุ่ม **"สั่งอาหาร"** → ออเดอร์ส่งไปที่ห้องครัว

### 2️⃣ หน้าครัว

1. เปิด `/kitchen.php`
2. ดูออเดอร์ที่เข้ามา (โหลดอัตโนมัติทุก 10 วินาที)
3. กด **"รับออเดอร์"** → เปลี่ยนสถานะเป็น "กำลังทำ"
4. กด **"ทำเสร็จแล้ว"** → เปลี่ยนสถานะเป็น "ทำเสร็จ"
5. กด **"เสิร์ฟแล้ว"** → เปลี่ยนสถานะเป็น "เสิร์ฟแล้ว"

### 3️⃣ คิดเงิน

1. เปิด `/billing.php`
2. เลือก **โต๊ะ** ที่ต้องการคิดเงิน
3. ตรวจสอบรายการอาหารทั้งหมด
4. เลือกวิธีการชำระ: **เงินสด / โอน / PromptPay / บัตร**
5. กด **"ชำระเงิน"**

### 4️⃣ ลูกค้าสั่งผ่านมือถือ (QR Code)

1. พิมพ์ QR Code จากหน้า `/admin/qr_tables.php`
2. แปะ QR Code ที่โต๊ะ
3. ลูกค้าสแกน → เปิดหน้าเมนู
4. เลือกอาหาร → หยิบใส่ตะกร้า → กด **"ส่งรายการสั่งซื้อ"**
5. ออเดอร์เข้า `/kitchen.php` โดยอัตโนมัติ

### 5️⃣ จัดการเมนู

1. เปิด `/admin/menu_manage.php`
2. กด **"เพิ่มเมนู"** → กรอกชื่อ, ราคา, หมวดหมู่
3. กด **"บันทึก"**
4. สามารถแก้ไขหรือลบเมนูได้

### 6️⃣ จัดการโต๊ะ

1. เปิด `/admin/tables_manage.php`
2. กด **"เพิ่มโต๊ะ"** → กรอกรหัสโต๊ะ, ชื่อ, จำนวนที่นั่ง
3. กด **"บันทึก"**

### 7️⃣ สร้าง QR Code โต๊ะ

1. เปิด `/admin/qr_tables.php`
2. ระบบจะแสดง QR Code ของทุกโต๊ะ
3. กด **"พิมพ์ทั้งหมด"** เพื่อปริ้นแปะโต๊ะ
4. หรือกด **"ดาวน์โหลด"** แต่ละโต๊ะ
5. หรือกด **"คัดลอกลิงก์"** เพื่อแชร์ลิงก์

## 🚀 Flow การทำงาน

### แบบที่ 1: พนักงานรับออเดอร์

```
ลูกค้ามาที่ร้าน
    ↓
พนักงานเลือกโต๊ะ → รับออเดอร์ที่ pos.php
    ↓
ออเดอร์ส่งไปที่ kitchen.php
    ↓
ครัวทำอาหาร → กด "ทำเสร็จ"
    ↓
พนักงานเสิร์ฟ
    ↓
ลูกค้ากินเสร็จ → คิดเงินที่ billing.php
    ↓
ชำระเงิน ✅
```

### แบบที่ 2: ลูกค้าสั่งผ่านมือถือ

```
ลูกค้าสแกน QR Code ที่โต๊ะ
    ↓
เปิด menu.php → เลือกอาหาร → สั่ง
    ↓
ออเดอร์เข้า kitchen.php โดยอัตโนมัติ
    ↓
ครัวทำอาหาร → เสิร์ฟ
    ↓
คิดเงินที่ billing.php
    ↓
ชำระเงิน ✅
```
